# Changelog

## 1.1.0 - 2026-08-25

### Added

- Per-label content grids from 1 x 1 through 3 x 3 with adjustable row and column proportions.
- Independent text, font, style, alignment, and flow settings for each content cell.
- Solid, dashed, and dotted printable label borders.
- Coordinate-aware content and layout copying, plus full-label copying.
- Five-step session undo and preview guide controls.
- Explicit template schema compatibility and current-feature JSON round trips.

### Changed

- Unified the browser preview, SVG export, PDF source, and print rendering around the canonical SVG output.
- Reorganized sheet, label, text, appearance, and image-positioning controls.
- Improved mobile preview containment, focused-label clipping, and responsive control layouts.
- Refreshed the application icon and documentation showcase with spaced labels.
